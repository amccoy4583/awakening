How to get a token — two minutes, once
  1. Go to github.com/settings/tokens and sign in.
  2. Press Generate new token, then choose Generate new token (classic).
  3. Under Note type Awakening schedule.
  4. Set Expiration to No expiration (or a date past October 12).
  5. Tick only the box marked gist. Nothing else.
  6. Press Generate token, copy the string that appears, and paste it above.

GitHub shows the token once. If you lose it, make another.

Recording on your phone. Open Voice Memos, record, then tap the memo and choose Save to Files. Come back here, press Choose a recording and pick it. It uploads and the link fills itself in. Then press Save at the bottom to publish it to everyone.
Your token needs one more permission

Uploading audio writes a file to your awakening repository, which the gist permission does not cover.

  1. Go to github.com/settings/tokens and open your Awakening schedule token.
  2. Tick repo as well as gist.
  3. Press Update token. The token itself does not change.

If you made the token before this, you may need to generate a new one and reconnect above.
